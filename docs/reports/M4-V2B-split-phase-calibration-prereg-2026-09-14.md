## 2. Lead decisions frozen by this document

**D1 — Declaration authority (lead).** Evaluation-only, deterministic, **closed-form** synthetic controls may directly declare `L`, `selected_b`, `H_w`, the world transforms/signs, and the per-axis `alpha` used to synthesize the patch. This is lawful because the control's synthetic geometry is its own construction input, is declared **before** synthesis, and never reaches the P0 producer: declared values are not production inputs. Production inputs remain exactly P0 §1 / V2-B §2; no declared value is admissible as evidence in a production path, and the producer receives no hypothesis, translation, anchor, tau, or ranking. The declared `alpha` is oracle truth: it is removed from the redacted corpus view passed to `predict` and lives only in the sealed label file.

**D2 — Two disjoint splits, exactly 96 controls and 864 observations each.** The split discriminator is `sigma = 0` for calibration and `sigma = 1` for evaluation, and it is bound into every observation identity and provenance digest (§3, §4). Each split is exactly: 16 textureless null, 16 same-block/invisible-seam null, 16 synthetic seam-null, 48 positive seam. The per-control `ordinal` is global `0..95`; class is derived from fixed ordinal ranges `0..15`/`16..31`/`32..47`/`48..95`; `control_id` hashes `{sigma, split, class, ordinal}`. Every control carries all three world axes and exactly 3 distinct frames per axis (9 observations; 864 per split, one P0 producer call each), balanced signs, `selected_b` from the finite positive dyadic binary64 set `{0.5, 1.0, 2.0}` with its exact `as_integer_ratio` binding, declared periods from the finite binary64 set frozen in §7 (`selected_b/period_pixels = 1/16` exactly), per-observation frame translations, boundary contrasts, and nuisance amplitudes, all closed-form and RNG-free. The two splits are **not** recipe duplicates: `sigma` changes `alpha`, `L`, the positive `delta`, the `selected_b`/`period_pixels` index, and the nontextureless `base`, so calibration and evaluation schedules, patch bytes, and digests differ. Each **observation** binds exactly one local axis `a` and owns its own `(H, W) = (64, 64)` patch (864 patches per split).

**D3 — Grid exactly 1000 tuples, strictly lexicographic.**

```text
tau_band                     in {0, 1/8, 1/4, 3/8, 1/2}        (5)
tau_margin                   in {1/8, 1/4, 3/8, 1/2, 1}        (5)
tau_energy                   in {0, 1/8, 1/4, 3/8, 1/2}        (5)
min_held_out_samples         in {1, 2, 4, 8}                    (4)
min_distinct_frames_per_axis in {2, 3}                          (2)
target_power                 = (1, 2)
```

5·5·5·4·2 = 1000; ascending nested iteration in exactly that order is already strictly increasing under `_split_calibration_tuple_lt` and duplicate-free.

**D4 — Metric definitions (resolves readiness §7.4).** `held_out_samples(o) = coverage["valid"]` of the **bound** `SplitSeamProfileEvidence` only. A **null false accept** for a control is: any world axis reported `determined` for that control under the tuple (per-hypothesis accepts are recorded but do not create one). A **positive success** for a seam control under a tuple is: `overall determined` **and** the emitted 3-axis `alpha` exactly equals the declared vector (`dTorus == 0`). `power = successes / 48`; the tuple is feasible iff every null has zero false accepts and `power >= target_power` with the exact integer test `2 * successes >= 48`. `tau_band=0` is not special-cased: it is infeasible by the §7 frozen assertion (at most 16/48 calibration positives), so the lexicographic scan must pass it over.

## 3. Canonical sample / control / corpus / label / prediction schemas

Canonical JSON is `SPLIT_PHASE_CANONICAL_JSON` (`sort_keys=True`, compact separators, `ensure_ascii=True`, `allow_nan=False`). Every `*_sha256` is lowercase SHA-256 over canonical JSON of the object with only its own digest field removed, except the two P0 framings: `patch_sha256 = SHA256(b"mc-photogrammetry-split-patch-v1" || uint64_le(rows) || uint64_le(columns) || uint64_le(byte_length) || P.tobytes("C", "<f8"))` and `payload_sha256 = SHA256(SPLIT_SEAM_PROFILE_PAYLOAD_VERSION || uint64_le(len(samples)) || samples || uint64_le(len(weights)) || weights || uint64_le(len(indices)) || indices)` in samples/weights/indices order. Reduced dyadics are `[numerator, denominator]`, canonical zero `[0, 1]`; finite floats convert exactly once with `Fraction(float.as_integer_ratio())`. `selected_b` is the one exception to the `[0,1)` reduced-dyadic rule: it is stored as an exact positive binary64 float plus its exact `as_integer_ratio` pair (`0.5`=[1,2], `1.0`=[1,1], `2.0`=[2,1]), converted exactly once with `Fraction(*selected_b_ratio)`; `[1,1]`/`[2,1]` are admissible because `selected_b` is not a `[0,1)` threshold.

**Observation record** (`observation_record`; exactly 864 per split; the calibration "sample"): `observation_id` (64-hex = `SPLIT_PHASE_CANONICAL_JSON({"sigma", "split", "control_id", "world_axis", "frame", "local_axis"})`), `sigma` (`0` calibration / `1` evaluation), `split`, `control_id`, `control_class`, `ordinal`, then exactly the ordered fields **`L_dyadic`, `T_dyadic`, `alpha_dyadic_hidden`, `H_w`, `selected_b`/`selected_b_ratio`, `period_pixels`, `local_axis a`, `world_axis w`, `world_sign s`**, plus `boundary_contrast`, `nuisance_amplitude`, `geometry` (the five-field `SplitPhaseGeometry`: `centre=[31.5,31.5]`, `extent=31.5`, `samples=64`, `rectified_pixel_step=1.0`, `period_pixels=period_pixels(k,w,sigma)`), `geometry_sha256`, `patch_float64_le_base64` + `patch_sha256`, `non_owning_profile_sha256` (the retained other-axis `d_profile_sha256`), `provenance_sha256`, `label_payload_sha256` (**sealed; absent from the redacted corpus**), `observation_sha256`. `alpha_dyadic_hidden` is sealed truth and is removed, together with any derived `ell_true`, from the redacted corpus; `H_w` and all provenance fields above are retained. Every observation identity/provenance digest carries `sigma`: `observation_id` is the preimage above; `provenance_sha256` is over `{"sigma", "split", "control_id", "observation_id", "L_dyadic", "T_dyadic", "H_w", "selected_b_ratio", "period_pixels", "a", "w", "s", "geometry_sha256", "boundary_contrast", "nuisance_amplitude"}`; and `observation_sha256` (the corpus `sample_sha256`) covers the whole record including both. `geometry_sha256` also differs across splits because `period_pixels` is selected with `sigma`.

**Control record**: `control_id`, `sigma`, `split`, `control_class`, `ordinal`, ordered `observation_ids` (9) and `patch_refs` (9), `control_sha256`. **Redacted corpus** (`corpus_<split>.json`): `corpus_version = "v2b-p0-calibration-corpus-1"`, `evaluation_only = true`, `sigma`, `split`, `patch_shape = [64, 64]`, `controls` (96 ordered redacted control records with their 9 redacted observation records each), `null_control_ids` (48) and `seam_control_ids` (48) (public by the D2 ordinal ranges), the ordered `sample_sha256s` (864 observation hashes; the `calibration_sample_sha256s`/`evaluation_sample_sha256s` input), `labels_sha256` (sealed label digest, by reference only), `corpus_sha256`. It is the corpus identity, the only corpus object passed to `predict`, and contains no label payload and no `alpha` truth.

**Sealed label file** (`labels_<split>.json`): the ordered 96-entry array `{control_id, class, components: [alpha_x, alpha_y, alpha_z] as reduced dyadics on seams, absence_reason on nulls}` plus `labels_sha256` over the array with only that field removed. It is written once in pass 1a, is never passed to or opened by `predict`, and is opened only by `score`.

**Prediction freeze** (`predictions_<split>.json`): `freeze_version = "v2b-p0-calibration-predictions-1"`, `evaluation_only = true`, `sigma`, `grid_sha256`, `corpus_sha256`, `labels_sha256`, `label_blind = true`, `per_control` (96 ordered entries with `control_id`, per-tuple per-axis determination status, emitted `alpha` reduced dyadics, per-hypothesis accept flags, the `zero_coverage`/`no_seam_evidence` observation sets, and `classifier_term_count`), per-observation `local_axis`/`consumed_profile_sha256`/`non_owning_profile_sha256` and the retained non-owning profile bytes, then `predictions_sha256` and `frozen_at` (ISO-8601 UTC, second precision). `frozen_at` is taken after `predictions_sha256` is computed and is **not** compared with the label-file mtime.

## 4. Corpus disjointness (frozen, digest-bound, re-checked at load)

(1) Calibration and evaluation are disjoint by `sigma`-bound digests and explicit set checks, **never by the split name alone** (`calibration`/`evaluation` are labels, not evidence): `set(calibration.observation_ids) ∩ set(evaluation.observation_ids) = ∅`, `set(calibration.sample_sha256s) ∩ set(evaluation.sample_sha256s) = ∅`, `set(calibration.provenance_sha256s) ∩ set(evaluation.provenance_sha256s) = ∅`, and `calibration_corpus_sha256 != evaluation_corpus_sha256`. (2) Nontextureless patch bytes are split-specific (the `2*sigma` base offset, the `sigma`-shifted `L` and `period_pixels`), so `set(calibration.nontextureless_patch_sha256s) ∩ set(evaluation.nontextureless_patch_sha256s) = ∅` is required. Textureless zero patches may share `patch_sha256`; for the corresponding schedule key `(k,w,j)`, the sigma-shifted period requires distinct `geometry_sha256`, and every cross-split textureless observation must have distinct `provenance_sha256` and `observation_id`/`sample_sha256`. Global geometry-hash sets need not be disjoint because each split intentionally reuses the same three period values. (3) Within `SplitPhaseCalibration` the implemented P0 overlap check is retained; the evaluator additionally requires both sample-hash tuples and both control-id tuples to be non-empty, ordered, and 64-lowercase-hex. (4) Calibration controls are disjoint from any control used to generate `G`-evidence hypotheses and from all evaluation controls; no V2-A/C2-R-B/P1-B hypothesis chain is run by this package, so the `H_w` used here are the D1 declarations only. (5) **Per-axis `G`/`D` coordinate disjointness:** inside every observation and for every world axis `w`, `G_a ∩ D_a = G_a ∩ X_a = D_a ∩ X_a = ∅` holds by P0 lane-index construction (`a` the local axis mapped to `w`); no sample coordinate is used by more than one role. Cross-axis lane overlap is allowed by P0, is outside the independence claim, and is never counted as a disjointness violation; only same-axis `D_a → G_a` influence is forbidden (`split_leakage`).

## 5. Exact two-pass procedure, process separation, and commands

Three invocations per split, each a separate OS process with a separate argv:

1. `synthesize` (pass 1a, label-bearing, evaluation-only oracle). Declares each control's class and the split's `sigma` (from `--split`), and **before** synthesizing `P` declares each observation's `(a, w, s, L, delta, T, alpha, H_w, selected_b, period, boundary_contrast, nuisance_amplitude)`; synthesizes the 864 patches, geometries, observations, and declared provenance closed-form by the §7 formula with `sigma` bound into every identity/provenance digest; writes the **redacted** `corpus_<split>.json` (patch bytes, `H_w`, geometry, and provenance retained; no `alpha` truth, no `ell_true`, no `delta`, no label payload, `labels_sha256` bound by reference) and the **sealed** `labels_<split>.json`, then emits its `labels_sha256`. The label path is never an argument to `predict`.
2. `predict` (pass 1b, label-blind). argv is exactly the redacted corpus path plus `--labels-sha256 <hex>`; it has no label path or handle and never opens `labels_<split>.json`. For each of the 864 observations it calls `produce_split_phase_evidence` once on that observation's patch/geometry with `reading_axis = w` and requires `status == "complete"` and `validate_split_phase_evidence(...) is True`. Each complete result carries **both** 64-bin local profiles (128 produced bins); only the profile for the observation's bound `local_axis a` is consumed, and the non-owning profile is retained and replay-checked (digest-bound, validated, never scored). For every grid tuple × observation × hypothesis × **bound-profile bin** × band side it computes the literal §7 `x_i`/`B`/`I`/`accept`, recording per-hypothesis accepts, per-axis determination, emitted `alpha`, and `classifier_term_count`; it writes `predictions_<split>.json` with `predictions_sha256` then `frozen_at`. It writes no label content and never imports `SplitPhaseCalibration`.
3. `score` (pass 2, label-using). Starts only after the `predictions_<split>.json` bytes, `predictions_sha256`, and `frozen_at` exist. It verifies `predictions_sha256`, opens `labels_<split>.json`, verifies `labels_sha256`, scores the frozen bytes under D4, selects the lexicographically first feasible tuple or returns typed `no_feasible_calibration`, builds and validates `SplitPhaseCalibration` with `tie_break="no_tie_break_abstain"`, and writes exactly `calibration.json` plus `score_audit_<split>.json`; corpus, labels, and predictions remain immutable and are never written by `score`. The evaluation split is never scored in this package (V2-B §15, separate later authorization).

Chronology: `frozen_at` is **not** required to precede the label-file mtime (the oracle may declare and seal labels before synthesis). The enforced order is: prediction bytes + `predictions_sha256` + `frozen_at` exist → `score` opens labels → the score audit records `scored_at > frozen_at`, with `scored_at` ISO-8601 UTC at second precision. Enforcement: (a) CLI arg separation, since `predict` accepts no label path and `score` is the only stage that accepts one; (b) an `open`/`Path.open` monkeypatch in the predict tests raises on any label path or label-content read, and an AST gate asserts the `predict` code path contains no label-file literal, no label read, and no label import; (c) the audit record checks `scored_at > frozen_at`.


## 6. Selection rule

For each tuple in the frozen lexicographic order, evaluate D4 against the frozen predictions; select the **first feasible** tuple (zero false accepts on all 48 nulls and `power >= (1,2)`). If no tuple is feasible, return the typed `no_feasible_calibration` and stop: never relax a bound, widen a band, add a fallback, or continue searching. A revision of any frozen parameter is a contract amendment and invalidates the experiment. `calibration_grid_sha256` must equal `frozen_grid.grid_sha256` (evaluator check, §8). The `tau_band=0` tuple is first in the frozen order but is infeasible (§7), so selection must advance past it rather than accept a trivial fit.

## 7. Independent oracle, mutants, generator, class patch formula, budgets

**Oracle.** Test-local, evaluation-only; **declares** the split's `sigma`, each observation's class, `alpha`, `(a, w, s)`, `L`, `delta`, `T`, `H_w`, `selected_b`, `period`, `boundary_contrast`, `nuisance_amplitude`, and the patch before synthesis; independently implements the literal `axis_transform` table, the forward/inverse equations, the `x_i` map with **no** half-bin offset, the inclusive `d1 <= tau_band` band, coverage normalization by `C[i]`, the `ell + 1/2` interior band, the `zero_coverage` refusal, and the open-form `E`/`C` reductions; checks exact recovery of the declared `alpha` with `dTorus == 0`; and asserts exact `Fraction` equality — no tolerance, since every synthetic value is dyadic or an exactly convertible finite float. The class truth is declared, never inferred: for seam-null it asserts the exact half-turn identity `B(h,o) == I(h,o)` for all `h` and every `tau_band`; for positive it asserts the contrast is at the declared `ell_true = mod(L + delta, 1)` and that `h = alpha` is the unique accepted hypothesis; textureless and same-block assert no acceptance. **Frozen `tau_band=0` infeasibility assertion.** For any observation with `delta != 0`, `ell_true` is exactly `1/32` from the nearest `x_i = (L + i/16) mod 1`, and every `ell(h) = mod(ell_true + s*m/16, 1)` for `m in {0,3,7,13}` is likewise a half-bin value, so the `tau_band=0` band is empty and the classifier refuses `zero_coverage`; a positive control is `overall determined` at `tau_band=0` only if all nine observations have `delta = 0`, which holds for exactly the 16 calibration positives with `sigma=0` and `(k-48)%3==0`. Hence calibration `tau_band=0` power is at most `16/48 < 24/48 = target_power`, no `tau_band=0` tuple is feasible, and the trivial fit is rejected. The oracle asserts this bound, asserts that every evaluation positive has `delta != 0` (so evaluation is scored on nonzero sub-bin offsets only, testing held-out interpolation), and asserts that no frozen-grid tuple with `tau_band=0` is reported feasible. No expectation is derived from the code under test; the oracle may not import `split_phase_calibration`, and `predict` may never read `alpha`/`ell_true`/`delta`.

**Required mutants (each must fail closed).** Textureless treated as zero/fabricated seam; uniform control determined; same-block null accepted; seam-null accepted; any null with one axis determined; **consuming or scoring the non-owning profile, or using its `E`/`C`/bins in `B`/`I`, determination, or power**; **dropping, mutating, or failing to validate the retained non-owning profile**; **binding the wrong local axis (always `u`/`v`, or ignoring `j` in `a`)**; **inferring the seam-null symmetry or the positive truth from the measured acceptance/argmax instead of the declared class/`alpha`**; widening `tau_margin`/`tau_band` to force a singleton; ranking by energy/residual/index/response/concentration/contributor order; half-bin offset in `x_i`; `(n, 2)` coordinate map instead of ordered `axis_bin_indices`; zero denominator treated as zero energy; reordered/gapped indices; non-canonical dyadic (`(0,2)`, even nonzero numerator, non-power-of-two denominator); duplicate/unordered grid tuple; grid substitution or a tuple outside the grid; split/corpus/sample-hash overlap; **a split-label-only reseal that relabels or renames a split without regenerating the `sigma`-bound observation/provenance bytes, or any disjointness claim resting on the split name**; **a `tau_band=0` false-feasibility claim (any reported `tau_band=0` feasible tuple, or any assertion that a nonzero-`delta` observation has an exact boundary bin)**; **a nontextureless patch-set overlap, or a corresponding-key textureless pair that shares geometry or any cross-split textureless pair that shares provenance/sample identity**; oracle expectation computed from the code under test; any production-input or GT/camera/F3/label import in the module (AST gate).

**Frozen generator (deterministic, RNG-free, byte-identical regeneration).** With global control ordinal `k in 0..95`, world axis `w in {0,1,2}`, frame `j in {0,1,2}`, split discriminator `sigma in {0,1}` (`0` calibration, `1` evaluation), `mod(a,n)` the nonnegative remainder, `frac` a reduced `Fraction`, and `d1(x,y) = min(|x-y|, 1-|x-y|)`:

```text
sigma                    = 0 (calibration) / 1 (evaluation)           # split discriminator
local_axis a(k,w,j)      = "u" if (k + w + j) % 2 == 0 else "v"       # lead-frozen bound axis
s(k,w)                   = +1 if (k + w) % 2 == 0 else -1             # balanced, stored
selected_b(k,w,sigma)    = B_SET[mod(k + w + sigma, 3)],  B_SET = (0.5, 1.0, 2.0)     # binary64
period_pixels(k,w,sigma) = P_SET[mod(k + w + sigma, 3)],  P_SET = (8.0, 16.0, 32.0)   # binary64
alpha(k,w,sigma)         = frac(mod(2*k + 3*w + sigma, 16), 16)       # sealed truth, hidden
L(k,w,j,sigma)           = frac(mod(2*k + 5*w + 3*j + sigma, 16), 16) # exact leading cell
delta(k,w,j,sigma)       = 0                             if control is null
                         = 0                             if sigma == 0 and (k - 48) % 3 == 0
                         = +1/32                         if (k + w + j + sigma) % 2 == 0
                         = -1/32                         otherwise  # positives; signed exact Fraction
ell_true                 = frac(mod(L + delta, 1))                    # exact = mod(L + delta, 1)
T(k,w,j,sigma)           = frac(mod(alpha - s*(L + delta), 1))        # frame translation, stored
H_w(k,w,sigma)           = tuple(frac(mod(alpha + frac(d, 16), 1)) for d in (0, 3, 7, 13))  # truth at d = 0
boundary_contrast        = float(1 + frac(mod(k + w, 4), 4))     in {1.0, 1.25, 1.5, 1.75}
nuisance_amplitude       = float(frac(1, 2) + frac(mod(k + 2*w, 4), 4))   in {0.5, 0.75, 1.0, 1.25}

                                              rectified_pixel_step=1.0, period_pixels=period_pixels(k,w,sigma))
```

**Class-specific patch (sufficient for byte-identical regeneration).** For `P` of shape `(64, 64)` with indices `r, c in 0..63`, let `t = c` if `a == "u"` else `t = r`, with `sigma`-specific nontextureless base:

```text

              / Fraction(*period_pixels.as_integer_ratio())) mod 1
base     = nuisance_amplitude / 8 + 2*sigma                  # exact; nontextureless only
positive      : q_t = base + boundary_contrast  if d1(x_t, ell_true) <= 1/16 else base
textureless   : q_t = 0
same-block    : q_t = base                                    # constant, invisible seam
seam-null     : q_t = base + nuisance_amplitude if floor(4 * x_t) % 2 == 0 else base   # q(x) = q(x + 1/2)

```
