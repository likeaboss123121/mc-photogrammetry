Implemented for exact-pin Astra and lead review. No ordinary screenshots, scene/camera/F3 data, ground-truth files or reference schematics were read. Accepted geometry source/tests and sealed IMAGE-03 artifacts remain untouched. No production import or integration.

Reciprocal Lowe ratio is a proposal filter, not geometric acceptance. `diagnose(frames)` accepts sorted opaque IDs and RGB uint8 arrays only. `calibrate_synthetic()` is a separate generated-fixture evaluator; its known transforms never enter fitting.

Budgets: geometry's32-frame/1MP-per-frame limits, legacy/extended copied-RGB and per-variant descriptor/report limits;700 features/variant/frame;64 scheduled pairs at32; six configured arms;376,320,000 total bidirectional descriptor comparisons and96MB serialized ablation output. AKAZE/ORB selection keeps the strongest700 with deterministic keypoint tie breaks and reports raw detection counts; SIFT ties exceeding700 refuse. Total descriptor budget is checked before matching the affected variant. Over-budget data refuses rather than truncating evidence or weakening geometric gates. Copied RGB/logical work/serialized bytes are bounded, not exact process RSS. The inherited12M-comparison budget for <=8 frames can refuse dense feature sets; this is an explicit resource refusal.

A canonical v2 outer receipt pins exact configuration, source geometry, every nested geometric report, extracted coordinates, detector counts, stage summaries, frame hashes, frame dimensions and total work. Every available arm's dimensions must equal the outer declaration; `verify_frame_binding` also compares both the declaration and all available arms against supplied RGB array shapes. Replay cross-checks every emitted track coordinate against extracted features, then delegates fit/held/cycle evidence replay to the pinned validator. A digest-only canonical check cannot authenticate a consistently resealed outer declaration against unseen pixels; source binding requires the arrays. `persist_report(path, report, frames)` therefore requires the original RGB arrays and verifies source binding before temporary creation. It does not independently authenticate OpenCV detection/RANSAC provenance. No-clobber publication validates first, writes/fsyncs temporary bytes, creates the target atomically and removes temporary files on errors.

## Synthetic definitions and preregistered selection

Fixed seed260108: four positive triples from one generated texture under scale/rotation/perspective plus brightness, pixel noise and occlusion; two negatives (randomly rotated repeated32px texels and independently randomized block textures). These are basic diagnostic fixtures, not a broad Minecraft benchmark.

- Eligible source feature: at least one extracted target feature lies within3px in both directions under the known projective transform.
- True proposal: a reciprocal feature pair passes those known-transform distances. Proposal recall = summed true proposals / summed eligible sources, separately conditioned on each detector's extracted features.
- Accepted support: fitted inliers plus jointly passing held correspondences from accepted pair models. Accepted precision = true accepted support / all accepted support. The oracle label is evaluation-only; geometric acceptance is independent.
- Positive support: at least one coherent three-view track; negative false support: any accepted pair model. A candidate needs >=3/4 supported positives, >=95% aggregate accepted precision, zero accepted-pair negative cases. Unavailable arms cannot pass.
- Passing candidates rank by supported-positive count, proposal recall, accepted precision, then frozen configuration order. No candidates passing means no chosen variant.

Result: `sift-wide-ratio`0.85 chosen from synthetic data only. Baseline:4/4 positive,0/2 negative,100% accepted precision,2830/6574 proposal recall=43.048%. Wide SIFT:4/4 positive,0/2 negative,100% precision,3152/6574 recall=47.946% (+4.898 percentage points). Low contrast ties their corresponding normal-contrast arm on this suite. ORB:3/4 positive,0/2 negative,99.723% accepted precision,2170/6298 recall=34.455%. This is feature-level calibration, not geometry/state accuracy or ordinary-image gain. All sweep/config thresholds were fixed before an ordinary-image run, which has not occurred.
