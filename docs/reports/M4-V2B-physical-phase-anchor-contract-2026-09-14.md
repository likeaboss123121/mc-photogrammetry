### 3.1 Exact values and canonical dyadic

Every numeric comparison is exact rational. Finite IEEE-754 inputs are converted exactly once with `Fraction(float.as_integer_ratio())`; every derived value uses `fractions.Fraction`. A **reduced dyadic** is `(numerator, denominator)` with `denominator = 2**k`, `k >= 0`, and either the **canonical zero `(0, 1)`** or `numerator` **odd** with `0 < numerator < denominator`. `(0, 2)`, `0` with any other denominator, a negative numerator, and any non-power-of-two denominator are `noncanonical_dyadic` and refused. Modular reduction into `[0, 1)` uses floor: `x mod 1 = x - floor(x)`, applied to `Fraction`, so it is exact and order-independent. No float accumulation decides any classification; floats appear only as serialized views. Measurement-uncertainty intervals (`phase_error_amplification`, `comparison_tolerance`, `closure_tolerance`, `tau_band`) are stored separately as frozen values and are **never** used to generate, prune, or order hypotheses.

### 3.2 Local axis to world component

For a reading `r` with local axis `a` (`u` = label 0, `v` = label 1) and accepted absolute C1 quadrant `q = absolute_quadrant`:

```text
(w, s) = plane_graph.axis_transform(a, q)        # exactly one world component
```

`q` is the accepted absolute quadrant (`0..3`, no implicit modulo); `w in {0,1,2}` is the single world axis and `s in {-1,+1}` the world sign. `q` shares the quadrant already bound by `residue_u`/`residue_v` in the accepted `ReadingLabelDomain`. `u` and `v` map to different world components through the same table (`_AXIS_TRANSFORMS`). V2-B **never** requires `residue_u == residue_v`, never collapses `u`/`v` into one scalar, and never compares across local axes except through `(w, s)`. A missing/refused quadrant, an out-of-range label, or any transform disagreement is `axis_transform_invalid` and abstains.

### 3.3 Per-reading origin, forward anchor, and inverse

The **only** accepted origin source is the unique `plane_relative_translation.C2RBTranslationClassCertificate` of the single accepted `C2RBComponentResult` (`outcome == "unique_validated"`, `exhaustive is True`, `cycle_rank >= 1`, `failing_chords` empty, `translation_classes` length 1, every `cycle_residuals` entry with `matching_provenance_count > 0`, and `placement_readiness == "ready"`). Its `gauge_anchor` frame has translation `((0,1),(0,1),(0,1))`; every other frame has exact `translations_dyadic_xyz`.

For reading `r` in frame `f`, local axis `a`, `(w, s) = axis_transform(a, q)`, let `T_f[w]` be the world-axis `w` component of the certificate translation for `f` and `L` the exact P1-B leading-edge cell coordinate (`PeriodicResidueCandidates.leading_cell_coordinate`, converted once). The anchor-frame origin and the anchor from a stored P1-B local candidate `c` are

```text
O(r,a) = (s * L + T_f[w]) mod 1
h(c)   = (s * c + T_f[w]) mod 1          # forward anchor
ell(h,o) = (s * (h - T_f[w])) mod 1      # inverse local seam position
```

with `c` and `L` converted exactly once from their stored floats. The local candidate already includes the P1-B leading term; V2-B validates the P1-B expression `(L + phase_fraction * b + k/q) mod 1` against the stored candidate set within the frozen interval and never recomputes or re-quantizes it. Fail closed (typed abstention for the affected observation, never an assumed zero) when: the certificate is absent or ambiguous; `T_f[w]` is missing for a reading's frame; `L` is `None` or its P1-B record carries a refusal; the P1-B replay disagrees; the origin cannot be expressed inside the isolation boundary; or a tolerance used in the replay differs from the accepted value. The types are `propagation_unavailable`, `translation_class_not_unique`, `certificate_mismatch`, and `propagation_origin_inconsistent`.

### 3.4 Replay precedence

No classification is reported before: scalar/type/tolerance validation; the §8 input gate; `validate_relative_translation_graph`; `validate_endpoint_provenance_result`; the P0 `validate_split_phase_evidence(record, P, *, geometry: SplitPhaseGeometry, partition_config: SplitPhasePartitionConfig, budget: SplitPhaseProducerBudget) -> bool`, which must return `True` (a `False` refuses `split_not_reconstructible`/`split_replay_mismatch`), with the pipeline-supplied in-memory `P` (missing/mismatched `P` refuses `p0_patch_unavailable`/`p0_patch_mismatch`); exact reconstruction of the G-only `PeriodicEnergyPhaseEvidence`/`PlaneReading` copy and the unmodified public P1-B replay from it; decode/re-hash/reconstruction of the embedded ordered `D` profile payloads; and exact reconstruction of the `(reading, local axis, world axis, sign)` table from the retained `ReadingLabelDomain`/`ReadingIdentity` records. A freshly re-sealed but semantically inconsistent record is `result_validation_mismatch`, never repaired. Inputs are never mutated.

## 4. Finite provenance-derived hypothesis set with ordered contributor provenance

For each world axis `w`, the candidate seam set is the finite, exactly reduced set `H_w = { h(c) : c in the accepted P1-B/V2-A candidate provenance that maps to w }`, built only from: every accepted `V2AEndpointResult.reading_domains[*].residue_u` and `.residue_v` `candidate_values` entry mapped by its own `local_axis_label`/`absolute_quadrant`; every accepted `C2RBEdgeCandidateRef` whose `residue_indices`/`match_identity` map to `w`; and every `PeriodicResidueCandidates.residue_candidates` entry already named by an accepted `source_record_sha256`.

Each distinct exact value in `H_w` retains its **complete ordered contributor list**: for every contributing record, `(source_kind, source_record_sha256, domain_sha256, local_axis, local_axis_label, absolute_quadrant, world_sign, frame_translation_dyadic, leading_cell_coordinate, selected_b, residue_index, hypothesis_sha256, contributor_order)`, in canonical source order. Deduplication of equal reduced `Fraction`s **merges digests only**: it never drops, reorders, or anonymizes a contributor. `contributor_count` and the ordered `contributors` tuple are part of the record and its digest. A hypothesis whose contributor list is empty, or whose provenance is refused or unavailable, is omitted with the typed reason recorded; if `H_w` is empty, axis `w` abstains as `no_hypothesis`.

`H_w` is bounded by `max_hypotheses_per_axis` and `max_hypotheses_total`; excess is `hypothesis_set_too_large`. There is **no** dyadic depth, no `max_anchor_depth`, no power-of-two grid, and no tolerance-selected subset: a tolerance may never add, drop, or order a hypothesis.

## 5. Path A: consistency-only, non-promotable

Path A may reuse retained `lattice_planes.PeriodicEnergyPhaseEvidence` (P1-A) `phase_uv_pixels`, `period_pixels`, `patch_centre_uv`, `extent`, `samples`, `response_magnitude_uv`, `profile_mass_uv`, `concentration_uv`, `unavailable_reason_uv`, and the V1 footprint only to ask whether that evidence is *consistent* with `H_w`. Path A is the same full-patch evidence that generated the P1-B hypotheses, so it cannot independently identify a physical seam. It therefore emits only `V2BConsistencyDiagnostic` with status `consistent`, `inconsistent`, `unavailable`, or `insufficient_data`. It may never emit `determined`, may never set `alpha`, and may never promote, unblock, or feed a placement path. A consistency diagnostic is not evidence and cannot be cited in a promotion case. This full-patch measurement is also the source of the frozen `period_pixels` context (P0 §5); Path A never re-estimates the period.

The independence boundary begins at the frozen rectified patch array `P` (P0 §1/§2) and is **conditional on the frozen `period_pixels`**: it begins **after period freeze**, claims **no** raw-image independence and **no** period-estimation independence, and does **not** claim that partitioning precedes period estimation (only the split phase/profile computation). Guard lanes cover only post-boundary profile/seam stencils with the exact integer radii named in `SplitPhasePartitionConfig` (`g >= max` radii; current pure lane sums are radius `0`). ## 7. Absolute boundary-vs-interior test and per-axis determination

For each world axis `w`, each hypothesis `h in H_w`, and each qualifying `D` observation `o` (reading, local axis, `(w, s)`), with the inverse local seam position `ell(h,o) = (s * (h - T_f[w])) mod 1`, V2-B reconstructs the ordered held-out `D` profile `E`/`C` and its `axis_bin_indices` from `SplitSeamProfileEvidence` and maps each profile bin `i` to the exact local residue `x_i = (L + selected_b * Fraction(i) / Fraction(period_pixels)) mod 1`, using the exact stored `L` (the P1-B `leading_cell_coordinate`), `selected_b` (the resolved downstream match/`PlaneReading` alternative), and `period_pixels` (the exact `float.as_integer_ratio()` of the stored value); there is **no** half-bin offset because `_periodic_energy_axis` indexes `np.arange(profile.size)`. V2-B **computes** the exact rationals `B(h,o) = (sum of E[i] over bins with d1(x_i, ell) <= tau_band) / (sum of C[i] over those bins)` and `I(h,o) = (sum of E[i] over bins with d1(x_i, (ell + 1/2) mod 1) <= tau_band) / (sum of C[i] over those bins)`; the band boundary is inclusive (`<=`), and a zero denominator refuses that observation as typed `zero_coverage` (never a fabricated zero, never silently dropped). P0 supplies no energy and no `tau_band`; both the samples and the coverage are frozen P0 outputs, and the binning is V2-B's. The preregistered **absolute** tests are:

```text
accept(o,h)  iff  B - I >= tau_margin  and  B >= tau_energy
                  and held_out_samples >= min_held_out_samples
reject(o,h)  otherwise
```

`tau_margin > 0`, `tau_energy >= 0`, `min_held_out_samples > 0`, and `min_distinct_frames_per_axis >= 2` are frozen only by the P0 calibration (§11). Hypothesis `h` is accepted for axis `w` iff it is accepted by every qualifying observation of that axis and supported by at least `min_distinct_frames_per_axis` distinct frames; any qualifying rejection rejects it. Then `axis w determined iff exactly one h in H_w is accepted`, otherwise abstained. Absent or below-floor evidence is `no_seam_evidence`; a zero-denominator observation refuses as `zero_coverage`, cannot accept, and is excluded from the qualifying set, so an axis with no qualifying observation abstains; two or more accepted hypotheses is `multiple_hypotheses_supported`; a rejected but uniquely provenance-implied hypothesis is `evidence_conflict`. There is **no** ranking, ordering, residual winner, magnitude comparison, or tie-break: a tie is an abstention, never resolved by index, energy, response, concentration, residual, or contributor order.

### 7.1 Overall anchor vector

`overall determined` iff axes `x, y, z` are each determined; `overall partial` iff at least one axis is determined and at least one abstained; `overall abstained` iff no axis is determined. `alpha = (alpha_x, alpha_y, alpha_z)` is populated only on `determined`, with each `alpha_w` equal to the unique accepted provenance-derived `h` (an exact reduced rational mod 1), never a raw measured float. `partial` and `abstained` carry the per-axis typed reasons. Placement stays blocked unless `determined`; V2-B never itself unblocks or writes placement.

## 8. Input gate: `endpoint_multiple` and non-uniqueness always abstain

V2-B abstains, before any hypothesis or pixel work, on every V2-A or C2-R-B state that is not strictly unique:

- `classification == "endpoint_multiple"` → `abstained/endpoint_multiple`, always, even if a single held-out hypothesis would otherwise pass. The retained `endpoint_multiple` witnesses are an arbitrary canonical-order pair, explicitly not a rank, and the frozen result is only a lower bound (`exhaustive is False`, `lower_bound_only is True`); it cannot certify that every compatible assignment projects to one anchor.
- `classification == "endpoint_none"` → `abstained/endpoint_none`.
- `translation_class_count != 1`, `exhaustive is not True`, `lower_bound_only is True`, `endpoint_assignment_count != 1`, more than one witness, a non-`complete` status, a refusal, or a budget failure → `abstained/input_gate_not_unique`.
- C2-R-B not `complete`/`ready`/`connected`, `len(components) != 1`, `outcome != "unique_validated"`, `cycle_rank < 1`, `exhaustive is not True`, non-empty `failing_chords`, any `matching_provenance_count <= 0`, or `len(translation_classes) != 1` → `abstained/input_gate_not_unique`.

This preserves the V2-A boundary: `endpoint_multiple` already blocks placement, and V2-B inherits the block rather than working around it.

## 10. Atomic budgets and precedence

`V2BAnchorBudget` has explicit positive exact-integer caps with no defaults (booleans invalid), at least: `max_readings`, `max_observations`, `max_frames`, `max_hypotheses_per_axis`, `max_hypotheses_total`, `max_contributor_refs_per_hypothesis`, `max_contributor_refs_total`, `max_source_records`, `max_boundary_interior_terms`, `max_d_profile_terms`, `max_payload_bytes`, `max_replay_crosslinks`, `max_pixel_samples`, `max_held_out_samples_per_reading`, and `max_split_reconstructions`. The P0 `SplitPhaseProducerBudget` separately caps lanes, patch samples, `G`/`D`/guard samples, `G` profile terms, the embedded `D` profile samples/weights/axis-bin indices as element counts `n` (`max_d_profile_terms` = `3*(H+W)` total array elements across both axes) and both axes' fully framed byte sequences (`max_payload_bytes` = `2*len(SPLIT_SEAM_PROFILE_PAYLOAD_VERSION)+48+24*(H+W)`), plus replay checks; the combined plan states the exact pixel, profile/payload, hypothesis, contributor, and cross-link counts before any pixel or hypothesis is inspected. ## 12. Exact vector circular metric

For exact rationals on the torus: `d1(x, y) = min(|x - y|, 1 - |x - y|)` and `dTorus(X, Y) = max over w of d1(X_w, Y_w)` (exact, L-infinity on `T^3`). `dTorus` is the frozen vector circular metric, used for consistency checks, hypothesis membership inside the frozen interval, and oracle comparison. It is symmetric, exact, and never float-accumulated. No other metric may be substituted at implementation time.
