## DDA correction and limits

Origin handling: for a ray whose origin lies exactly on a grid plane and whose component points negative, initialization moves into the voxel occupied for positive ray depth and never tests the floor-selected zero-length cell. A ray parallel to a grid plane is typed unknown. Crossing ties use exact equality of represented crossing parameters, not epsilon tolerance. Exact ties advance all tied axes at once, so no zero-length side voxel is visited; if the destination owner has tied face ownership, it is unknown. Near-equal positive crossings are stepped separately, preserving the positive-length side voxel. Depth is checked before occupancy. Domain exit, grid gaps, tied ownership, depth/step cap, and unsupported geometry/render prefixes are unknown, never treated as air or negative.

The 22-name, empty-properties allowlist has audited full-cube geometry and alpha-255 texture support in the pinned evaluation 1.21.5 JAR listed above. This is evaluation-asset evidence only: effective capture-time client render-layer behavior and exact capture asset identity are unbound, so these assumptions support proxy classifications only and no certified hit. Other nonair states, including partial, pane, leaf, fluid, waterlogged, and unknown models, stop the ray as unsupported. Known context first hits outside the target region are retained and excluded from the target scoring denominator. The context contains static blocks only: entities, transient state, transparent/cutout/fluid compositing, resource-pack effects, and unmodelled shape protrusions remain unrepresented. Results therefore describe a version-matched evaluation-asset static-block proxy, never certified capture correspondence or screenshot correctness.

Native recovered camera estimates are kept distinct from the posthoc capture camera. Capture focal length is 779.422863 px; native estimate is 779.129582 px. This calibration/pose difference limits exact feature-ray attribution; the scorer makes no independent optical-calibration claim.

The proxy pair denominator is constructed from all 3,562/3,737 frozen detected feature points after raying every feature in both images. A unique pixel pair enters the proxy same-surface denominator only if both first static hits are supported, in the target region, on the same block cell/face, and within 1/16 block. All 7,695 reciprocal candidate edges are present and untruncated; all 12 stored native mode selections are scored, retaining raw and unique pixel-pair counts. Unknown and outside-target rows are explicit exclusions.
