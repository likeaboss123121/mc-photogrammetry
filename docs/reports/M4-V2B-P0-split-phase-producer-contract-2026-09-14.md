## 2. Partition model (per reading, per local axis)

`P` has shape `(H, W)` = `(rows, columns)`. Local `u` is the column profile; local `v` is the row profile.

- **`u`**: lanes are disjoint, contiguous row-index subsets; lane `i` is `P[rows_i, :]`, its profile the column sum over `rows_i`; every lane keeps all `W` columns. `u` never partitions columns.
- **`v`**: lanes are disjoint, contiguous column-index subsets; lane `j` is `P[:, cols_j]`, its profile the row sum over `cols_j`; every lane keeps all `H` rows. `v` never partitions rows.

The lanes totally and disjointly cover the orthogonal index range (`rows` for `u`, `columns` for `v`). Roles come from §3 as three **contiguous** lane blocks: **`G`** — generation lanes, whose profile alone may feed G-phase evidence; **`D`** — determination lanes, whose profile alone may feed the held-out `SplitSeamProfileEvidence` from which V2-B later computes boundary/interior energy; **guard** — neither, covering only the post-boundary profile/seam stencils at the single `G`/`D` adjacency (§3). Guard lanes address stencils computed **on `P`**, never raw-source resampling.

**Cross-axis overlap is allowed.** A sample may belong to a `u` lane and a `v` lane; `axis_transform(0, q)` and `axis_transform(1, q)` map `u`/`v` to **distinct** world axes for every accepted quadrant (`_AXIS_TRANSFORMS`). Independence is claimed only **within one mapped world axis**: `D_a` never influences `G_a`. No independence is claimed across distinct mapped world axes, for a shared sample, or for the raw source image behind `P`; every per-axis claim is conditional on the frozen `period_pixels` and begins after period freeze, with no period-estimation independence; cross-axis overlap is explicitly outside the independence claim.

`axis_label in {"u", "v"}`; `lane_count = N`; `orthogonal_extent = E` (`W` for `u`, `H` for `v`); `partition_config` must be a validated `SplitPhasePartitionConfig`, and `m`, `g`, `selector_salt`, and the version bytes are read **only** from it, never from a caller scalar; after the domain checks frozen below, the function evaluates the §3 min-lane refusal before orientation/role assignment and returns the typed shape-(ii) `SplitPhaseLaneRole(refusal="selector_min_lanes_unmet")` (never a bare refusal string and never a bare `SplitPhaseRefusal`) before assigning any orientation, lane, or role. It never reads `P`, pixels, phase, residue, energy, candidates, translation, frame identity, or outcome, and never branches on a measured value. `SPLIT_SELECTOR_VERSION = b"v2b-p0-selector-1"` is frozen version **bytes** (not a string); `SPLIT_SEAM_PROFILE_PAYLOAD_VERSION = b"v2b-p0-seam-profile-1"` is the frozen payload-framing version **bytes** (not a string) prefixed in every `payload_sha256` (§6/§10). **`lane_role` result is explicit and has no hidden state.** It returns the frozen record `SplitPhaseLaneRole` with exactly the ordered fields `role: str | None`, `orientation: int | None`, `refusal: str | None`, and `role_sha256: str`; validation admits exactly two disjoint shapes: (i) `role in {"G","D","guard"}`, `orientation in {0,1}`, `refusal is None`; or (ii) `role is None`, `orientation is None`, `refusal == "selector_min_lanes_unmet"`; any other combination is `selector_role_invalid`. `lane_role` evaluates the min-lane predicate `N < 2*m + g` first and, when unmet, returns shape (ii) **before** assigning any orientation, lane index, or role; otherwise it returns shape (i) with `orientation = SHA256(C)[31] & 1`. `lane_role` never reads the patch, pixels, phase, residue, energy, candidates, translation, frame identity, or any outcome, and never branches on a measured value; `axis_label` is exactly `str` `"u"`/`"v"`; `lane_index`, `lane_count`, and `orthogonal_extent` are exact `int`s (`bool` is rejected and is not a valid int), with `lane_index` in `[0, N)` and `lane_count`/`orthogonal_extent` the caller-supplied shape-derived `N`/`E` (`N = H`, `E = W` for `u`; `N = W`, `E = H` for `v`) each `>= 1`, re-checked against the patch shape by the producer/validator; any wrong type, `bool`, or out-of-range value makes a direct pure `lane_role` call raise `ValueError` with the exact reason `selector_domain_invalid` (evaluated before the min-lane predicate), while the min-lane case stays the typed shape-(ii) `SplitPhaseLaneRole`; the producer maps every such validation/domain failure to an atomic refused `SplitPhaseProducerResult`. `split_phase_lane_plan` is a separate pure function returning `SplitPhaseLanePlan` (frozen ordered fields/types/validation/digest in §6) or the shape-(ii) `SplitPhaseRefusal(reason="selector_min_lanes_unmet")` for the min-lane case; a `split_phase_lane_plan` domain error returns `SplitPhaseRefusal(reason="selector_domain_invalid")`; it introduces no additional hidden state and is the sole source of the §4 coordinate sets.

`SplitPhasePartitionConfig` is a frozen record with exactly: `partition_version` (str), `selector_version` (the frozen bytes), `selector_salt` (fixed built-in str), `min_role_lanes` (int `m >= 1`), `profile_stencil_radius_samples` (int >= 0), `seam_stencil_radius_samples` (int >= 0), `guard_lanes` (int `g`), where `g >= max(profile_stencil_radius_samples, seam_stencil_radius_samples)`. Current lane sums are pure sums, so both radii are `0` and the built-in config sets `g = 0`; any later stencil must raise `g` to at least its radius. **Lane count and ranges are frozen from shape/config only.** For local axis `u` the lane axis length is exactly `N = H` (rows) and the orthogonal extent is `E = W` (columns); for local axis `v`, `N = W` (columns) and `E = H` (rows). The number of lanes is exactly `N`, never a caller scalar and never derived from pixels. With `r = N - g`, `nG = r // 2`, `nD = r - nG`, the three contiguous roles are exactly orientation 0: `G = [0, nG)`, `guard = [nG, nG+g)`, `D = [nG+g, N)`; orientation 1: `D = [0, nG)`, `guard = [nG, nG+g)`, `G = [nG+g, N)`. Lane index `i` therefore maps to the half-open row range `[i, i+1)` in `u` and to the half-open column range `[i, i+1)` in `v`; the profile axis retains every orthogonal index `[0, E)`. Because `N`, `nG`, `nD`, `g`, and every range are functions of `(H, W)` and the validated `partition_config` alone, the partition is fully determined before any pixel is read and is byte-identical on re-derivation.

Canonical orientation input `C` is the UTF-8 byte string of `json.dumps({"axis": axis_label, "lane_count": N, "orthogonal_extent": E, "salt": partition_config.selector_salt, "selector_version": partition_config.selector_version.decode("ascii")}, sort_keys=True, separators=(",", ":"), ensure_ascii=True, allow_nan=False)`. `orientation = SHA256(C)[31] & 1` (the least significant bit of the 32-byte digest). With `r = N - g`, `nG = r // 2`, `nD = r - nG`: **orientation 0** gives contiguous `G = [0, nG)`, `guard = [nG, nG+g)`, `D = [nG+g, N)`; **orientation 1** swaps the roles around the identical guard band: `D = [0, nG)`, `guard = [nG, nG+g)`, `G = [nG+g, N)` (size `nD`). Lanes are always three contiguous index blocks; the guard block is empty exactly when `g = 0`, in which case the zero-width `guard` role contributes **no** `SplitPhaseLaneSet` record and no guard range (it is omitted, never emitted with `lane_index_stop == lane_index_start`).

**Min-lane refusal first after domain validation.** `m` and `g` come only from the validated `partition_config`; the selector evaluates `N < 2*m + g` (equivalently `nG < m` or `nD < m`) **before any orientation, lane, or role assignment**, refuses with `selector_min_lanes_unmet`, and produces no partition, lane, role, or digest. Otherwise `|G| = nG >= m` and `|D| = nD >= m`. This refusal is returned as the frozen shape-(ii) `SplitPhaseLaneRole` (§3) by `lane_role` (never a bare refusal string or `SplitPhaseRefusal`) and as `SplitPhaseRefusal(reason="selector_min_lanes_unmet")` by `split_phase_lane_plan`, never as a bare role string and never with an orientation bit set.

Required guarantees: (1) `G_a ∩ D_a = ∅` by lane index, for each axis `a`; (2) `G_a`/`D_a` nonempty exactly under the refusal predicate; (3) every `G`/`D` stencil stays inside its own lanes because `g` covers the frozen integer radii (no other footprint bound and no `cv2.INTER_LINEAR` support claim is used); (4) identical evaluation for both axes with only `axis_label`/`orthogonal_extent` varying; (5) re-deriving the partition or permuting lane inspection order yields byte-identical roles and digests.

## 4. Coordinate sets, counts, digests, replay

Per reading `r` and local axis `a`, with lane index sets `G_lanes(a)`, `D_lanes(a)`, `X_lanes(a)`:

    a = u:  G_u = {(row, col) : row in G_rows, 0 <= col < W}
            D_u = {(row, col) : row in D_rows, 0 <= col < W}
            X_u = {(row, col) : row in X_rows, 0 <= col < W}
    a = v:  G_v = {(row, col) : col in G_cols, 0 <= row < H}
            D_v = {(row, col) : col in D_cols, 0 <= row < H}
            X_v = {(row, col) : col in X_cols, 0 <= row < H}

Required invariants: `G_a ∩ D_a = G_a ∩ X_a = D_a ∩ X_a = ∅`; `G_a ∪ D_a ∪ X_a` is exactly the full `H*W` coordinate set; `|G_a| + |D_a| + |X_a| = H*W`. Counts `|G_a|`, `|D_a|`, `|X_a|` and the lane index ranges are retained; each per-axis role set with a **nonempty** lane-index block is serialized as exactly one `SplitPhaseLaneSet` record with the §6 ordered fields, whose ranges are the §3 shape/config-derived blocks and whose `sample_count` is exactly `(row_stop-row_start)*W` (`u`) or `(column_stop-column_start)*H` (`v`); a zero-width role (the guard role exactly when `g = 0`) is omitted and produces **no** `SplitPhaseLaneSet`, so a `complete` result carries exactly four nonempty G/D lane-set records (`G_u`, `D_u`, `G_v`, `D_v`, ordered by local axis then by role) when `g = 0` and exactly six (adding `X_u`, `X_v`) only when `g > 0`.

Retained digests (lowercase SHA-256 over canonical JSON: `sort_keys=True`, compact separators, `allow_nan=False`): `selector_salt_sha256`, `partition_sha256` (axis roles, lane index ranges, salt, `(H, W)`, geometry, config version), `G_a_sha256`, `D_a_sha256` (over the full ordered 2D `D_a` lane coordinate set of this section, never the reduced axis-bin indices or the recovered `D` energies), `X_a_sha256`, `producer_input_sha256`, `result_sha256`. `patch_sha256`, `g_profile_sha256`, `d_profile_sha256`, `producer_input_sha256`, and `result_sha256` bind **value content**, while `G_a_sha256`/`D_a_sha256`/`X_a_sha256` are **coordinate-set digests only** over the lane coordinate sets of this section built from shape and validated partition config alone, never over any patch or profile value, so mutating a value at a fixed partition leaves the partition, lane sets, selector, and all coordinate digests unchanged (only `patch_sha256`, the per-axis `g_profile_sha256`/`d_profile_sha256`, `producer_input_sha256`, and `result_sha256` may change). The patch itself is content-addressed by `patch_sha256` (shape, dtype, byte digest) or, only when `H*W <= max_inline_patch_samples`, a bounded canonical inline array (§6).

**Replay.** `validate_split_phase_evidence(record, weights_patch, *, geometry: SplitPhaseGeometry, partition_config: SplitPhasePartitionConfig, budget: SplitPhaseProducerBudget)` recomputes the selector roles, both coordinate sets, all counts, all digests, the `G`-only phase evidence, and the embedded `D`-only profile payload (never a boundary/interior energy) from retained records and the supplied frozen patch; it **decodes** each `*_base64` field to canonical little-endian bytes, checks the declared dtype/encoding, shape/count, and the frozen `payload_sha256` framing, re-hashes the declared `E`/`C`/index arrays and the full 2D `D_a` lane set to `payload_sha256`/`d_profile_sha256`/`D_a_sha256`/`seam_evidence_sha256`, and **reconstructs** the payload, then requires a byte-identical record; `validate_split_phase_evidence(...) -> bool` returns `True` only when the supplied `SplitPhaseProducerResult` is `complete` and its full replay and canonical bytes match, and returns `False` for every non-complete, malformed, missing, mismatched, or refused case, never raising for any evidence mismatch (only direct programmer type/domain errors raise, per §3); the retained `period_pixels` must equal the supplied frozen context. `G_a` must be reconstructible from the retained lane ranges and geometry **without** the source image. A mismatch is `split_replay_mismatch`; a missing/ambiguous lane record, a `G` record that cannot rebuild its `PeriodicEnergyPhaseEvidence`/`PlaneReading`, or a `D` payload whose base64/bytes/shape/counts do not decode, re-hash, or reconstruct is `split_not_reconstructible`. No classification is reported before this replay. A missing supplied in-memory frozen rectified structural weights patch `P` is `p0_patch_unavailable`; a `P` whose shape, dtype, or byte digest does not match the result's `SplitPhasePatchRef.patch_sha256` is `p0_patch_mismatch`. P0 does **not** generate P1-B candidates; that replay belongs to later V2-B (§8).

## 5. Legacy full-patch API unchanged, nonpromotable

`lattice_planes._periodic_energy_measurements`, `_periodic_energy_phase_evidence`, `_phase_pixels`, and `supported.phase_at_period` keep their exact current full-patch semantics and current bytes. They produce no `G`/`D`/guard sets, carry no split evidence, and are **nonpromotable**: V2-B may use them only through its consistency-only Path A diagnostic, never for determination, never to authorize an anchor. A record that presents a full-patch measurement as split evidence is refused as `legacy_full_patch_nonpromotable`. The frozen `period_pixels` consumed by the split producer is exactly the period already derived by this existing full-patch measurement (or the accepted P1-A reading period); the split producer never re-estimates it.

## 6. Records, refusals, budgets, persistence

All public records are frozen, slotted, self-validating, JSON-safe, and content-addressed; exact numeric fields are reduced `Fraction`s, where a reduced dyadic is `(numerator, denominator)` with `denominator = 2**k, k >= 0` and either the **canonical zero `(0, 1)`** or `numerator` odd with `0 < numerator < denominator`. `(0, 2)` or a non-power-of-two denominator is `noncanonical_dyadic`. `SPLIT_PHASE_CANONICAL_JSON(value)` is exactly `json.dumps(value, sort_keys=True, separators=(",", ":"), ensure_ascii=True, allow_nan=False).encode("utf-8")`. Every `*_sha256` digest is `SHA256` of that byte string over that record's own ordered field dict with only the digest field itself removed, except the two frozen framings `payload_sha256` and `patch_sha256` (below). Serialization is exact and deterministic: `None` -> `null`; `bytes` -> lowercase hex in a field named `<name>_hex`; a reduced dyadic -> a two-element JSON array `[numerator, denominator]` of exact ints; a finite float -> the exact `json.dumps` shortest round-trip rendering; a tuple -> a JSON array in frozen order; a nested record -> its own canonical dict.
