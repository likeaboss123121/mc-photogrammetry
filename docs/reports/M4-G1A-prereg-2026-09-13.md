## Scope and invariant behavior

This is an exact computational unblocking of plane_graph.solve_component only. Preserve its objective, match and plane identity, per-reading b choices, quadrant semantics, tolerances, cost terms, tie order, ambiguity policy, alternative limit, output schema, and all typed result reasons. No match generation, edge voting, graph redesign, equal-b identity rule, threshold tuning, evaluator/GT, material, capture, CLI, or default-path change.

The solver sorts frame IDs, fixes the first frame's quadrant to zero as its gauge, and exhaustively enumerates every tail in product(range(4), repeat=n-1), exactly 4^(n-1) assignments. For eight R4 frames this is 4^7 = 16,384. Set MAX_ASSIGNMENTS to exactly 16,384: it admits every possible eight-frame quadrant assignment and rejects nine or more frames (4^8 = 65,536) before enumeration with the existing typed reason component_too_large. This is the smallest cap that fully supports the authorized eight-view case and a hard deterministic work bound; no assignment is pruned. Retained alternatives remain capped at eight.

The unchanged solver objective is: for active matches consistent with a complete assignment, solve the existing least-squares translations per world axis; cost is sum((1-resultant[axis])*axis_face_observations) + 0.1*unresolved_frames + 0.1*(1-mean_active_match_score). Sort by (cost, lexicographic quadrant tuple); preserve integer_tolerance=0.15, min_resultant=0.90, ambiguous_margin=0.02, and the current terminal-reason precedence. Every chosen match continues to identify its per-frame reading index and its selected left_b/right_b. No b/support equality is introduced as plane identity.
